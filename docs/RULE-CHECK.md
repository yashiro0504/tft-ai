# 규칙 검증 · 게임 사실 탐지

2026-10-22 · 쌓인 랭크 보드로 코칭 규칙과 게임 사실을 확인한다. 모델 학습이 아니라 **규칙을 데이터로 검증하는 일**이다.
같은 날 두 번의 오진단('1성 4·5코 캐리 + 아이템 = 나쁨', 장로 드래곤 2칸 미반영)이 모두 규칙을 짐작으로 넣어서 생겼다.

| 명령 | 하는 일 |
| --- | --- |
| `npm run rules:check` | 장면 규칙(lib/keyMoments 실제 코드)이 뜬 보드가 **같은 레벨 보드보다** 실제로 등수가 나쁜지 잰다. 코스트·개수 기준을 바꾼 탐침도 함께 |
| `npm run facts:detect` | ① 2칸 기물 후보 ② 시너지 인원 이상(2명 계산·사전 누락) ③ 2성·아이템이 한 번도 없는 기물 ④ 코스트표·이름·단계표 누락 |

공통 옵션: `--source=db|ladder|fixtures` (기본: DB 시크릿 있으면 db → `data/ladderBoards.json` → 골든셋) · `--patch=16.20` · `--max-matches=3000` · `--out=파일.md` · `--strict` (문제 있으면 종료 코드 1).

- 자동 실행: `.github/workflows/rules-check.yml` 매일 11:45 KST. Riot 호출 없이 DB 만 읽으므로 **개발 키로도 충분**하다. 결과는 Actions 실행 요약 · 노란 경고 주석 · `rules-report` 아티팩트.
- 판정: 같은 레벨 보드끼리의 평균 등수 차이(+ = 장면이 뜬 보드가 나쁨). |차이| ≥ 0.25 이고 95% 구간이 0을 넘으면 `✓ 근거 있음` / `✗ 반대`, 해당 보드 30개 미만은 `표본 부족`.
- `sameComp` 는 정의상 1등 보드에서 뜰 수 없어 1등을 빼고 비교한다 — 그래도 편향이 남으니 참고만.
- 탐지 결과는 **확인할 목록**이다. 코드는 자동으로 고치지 않는다. 확인 후 게임 기준 DB 를 재생성하거나(`npm run build:gamedata`) Community Dragon 에 없는 사실이면 `lib/gameData.overrides.json` 에 근거와 함께 적고, 이미 아는 시너지 2명 계산은 `scripts/detectGameFacts.js` `KNOWN_TRAIT_DOUBLE` 에 적는다.

## 2026-10-27 · 1성 캐리 규칙을 레벨별 상점 확률로 (래더 9,952보드, `--source=ladder`)

'1~3코스트 캐리만'이던 `carryOneStar` 를 "최종 레벨까지 캐리 코스트가 상점에 30% 이상 나온 레벨을 지났으면"으로 바꿨다
(`lib/shopOdds` `CARRY_STAR_ODDS_MIN`, 확률표는 게임 파일 — [GAME-DATA.md](GAME-DATA.md#레벨별-상점-확률-shopodds)).

| 조건 | 해당 보드 | 같은 레벨 비교 차이 | 판정 |
| --- | ---: | ---: | --- |
| 예전 규칙 (1~3코스트 1성 캐리) | 16 | +1.26 ±1.37 | 표본 부족 |
| 1성 4코스트 캐리 — 예전엔 "후반 정상 운영"으로 제외 | 245 | +2.25 ±0.18 | ✓ 근거 있음 |
| **새 규칙 (상점 30%+ 레벨을 지난 코스트)** | **246** | **+2.27 ±0.19** | ✓ 근거 있음 |
| 하한 20% / 25% / 35% | 254 / 252 / 12 | +2.17 / +2.20 / 표본 부족 | 30% 와 거의 같음 · 35% 는 4코스트가 빠짐 |
| 1성 5코스트 캐리 · Lv.9 이하 (여전히 제외) | 343 | +2.36 ±0.2 | ✓ — 아래 참고 |

- 하한 30%: 4코스트 Lv.8(30%)부터 대상, 5코스트는 Lv.10(25%)까지 대상 아님. 20·25% 와 결과가 거의 같아 5코스트 Lv.10 을 빼는 쪽을 골랐다.
- 1성 5코스트 캐리도 같은 레벨에서 등수가 나쁘다(+2.36). 하지만 그 레벨 5코스트는 상점 15% 이하라 2성은 운에 가깝고 선택으로 바꾸기 어렵다.
  정답셋의 1등 판(KR_8427833164, Lv.9 1성 장로 드래곤 BIS)도 정상 운영이다 — 장면으로 내지 않는다.
- 3코스트는 Lv.7(40%)부터 대상이 됐다. 예전엔 Lv.6 이하 1성 3코스트 캐리도 장면이었다 (래더 11보드로 드물다).
- 같은 레벨 비교도 탈락 시점 편향이 남는다 (일찍 진 보드는 2성으로 올릴 시간이 짧았다). 차이 전부가 1성 탓은 아니다.
